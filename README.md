# Agent SOC Analyst Junior — IA Avancée et Automatisation

## Installation
1. Cloner ou placer le projet dans un dossier local.
2. Créer l'environnement virtuel : `python -m venv venv` et l'activer.
3. Installer les dépendances : `pip install google-genai python-dotenv mcp numpy`
4. Configurer le fichier `.env` à partir de `.env.example` en y insérant votre clé `GEMINI_API_KEY`.

## Exécution
Lancez l'agent interactif :
```bash
python agent_soc.py
